# 国产与主流 Android 系统真机设置与保活完全指南

由于各家国产定制系统（ROM）对本机无线调试与 `Instrumentation` 权限委托增加了不同的安全开关，首次使用「美境（Stateside）」时，只需花 1 分钟按对应品牌开启下方**唯一必开项**，后续即可日常一键秒开。

---

## 1. 小米 / REDMI（澎湃 HyperOS 1 / 2 / 3）

### 首次解锁与必开开关
1. **开启开发者选项**：进入 `设置 → 我的设备 → 全部参数与信息`，连续点击 7 次 **「OS 版本」**。
2. **进入开发者选项**：进入 `设置 → 更多设置 → 开发者选项`。
3. **关键必开项（缺一不可）**：
   - 打开 **「无线调试」**（弹窗勾选 *始终允许在此网络上调试*）；
   - 往下滑找到 **「USB 调试（安全设置）」** 并打开（需登录小米账号并连续完成 3 次倒计时确认）。
   > 若未打开「USB 调试（安全设置）」，澎湃系统会拦截 `UiAutomation` 特权借权，导致无法修改双卡国家码与应用语言。

### 日常保活与防掉开关贴士
- **切勿点击「手机管家 → 一键优化 / 体检」**：澎湃手机管家的一键体检默认会把「关闭开发者选项」作为加分优化项，点击后会导致无线调试被自动关掉。可在手机管家体检结果页长按「开发者选项」设为忽略。
- 若开启了「手机重启后自动恢复美境」，建议在 `应用设置 → 美境 → 省电策略` 中设为 **「无限制」**，并开启 **「后台自启动」**。

---

## 2. OPPO / 一加 / 真我（ColorOS 14 / 15 / 16 / 17）

### 首次解锁与必开开关
1. **开启开发者选项**：进入 `设置 → 关于本机 → 版本信息`，连续点击 7 次 **「版本号」**。
2. **关键开关说明（按系统版本区分）**：
   - **ColorOS 16 / 17（Android 16 / 17，如一加 15T 等新机）**：系统已移除旧版「禁止权限监控」并原生放行无线调试特权委托，**仅需直接打开「无线调试」（勾选 *始终允许在此网络上调试*）即可，无需寻找任何额外开关！**
   - **旧版 ColorOS 14 / 15（Android 14 / 15）**：进入 `设置 → 系统与更新 → 开发者选项`，若遇权限拦截提示，可滑到页面最底部打开 **「禁止权限监控」**，再打开 **「无线调试」**。

### 日常保活贴士
- ColorOS 锁屏后若通知栏顶部出现黄色「开发者选项正在运行」横幅，请勿点击横幅上的关闭按钮。
- 如需开机自动静默恢复，请在 `应用详情 → 耗电管理` 中允许 **「完全后台行为」** 与 **「允许自启动」**。

---

## 3. vivo / iQOO（OriginOS 4 / 5 / 6）

### 首次解锁与必开开关
1. **开启开发者选项**：进入 `设置 → 系统管理 → 关于手机 → 版本信息`，连续点击 7 次 **「软件版本号」**。
2. **关键必开项**：
   - 进入 `设置 → 系统管理 → 开发者选项`；
   - 同时打开 **「USB 调试」** 与 **「无线调试」**（弹窗勾选 *始终允许在此网络上调试*）。

### 日常保活贴士
- 如需重启自动恢复美境与桌面守卫快捷方式，请在 `设置 → 电池 → 后台耗电管理` 中将「美境」设为 **「允许后台高耗电」**，并在权限管理中允许 **「桌面快捷方式」** 权限。

---

## 4. 荣耀（MagicOS 8 / 9 / 10）

### 首次解锁与必开开关
1. **开启开发者选项**：进入 `设置 → 关于手机`，连续点击 7 次 **「版本号」**。
2. **关键必开项（注意顺序）**：
   - 进入 `设置 → 系统和更新 → 开发人员选项`；
   - **先开启「“仅充电”模式下允许 ADB 调试」**，再开启 **「无线调试」**。
   > 若未开启“仅充电”允许调试，MagicOS 在拔掉数据线或锁屏休眠后可能自动断开无线调试。

### 日常保活贴士
- 在 `设置 → 应用 → 应用启动管理` 中找到「美境」，关闭「自动管理」，手动勾选允许 **自启动、关联启动、后台活动**。

---

## 5. 三星（One UI 6 / 7 / 8）

1. **先检查自动拦截器**：进入 `设置 → 安全与隐私 → 自动拦截器（Auto Blocker）`，确保处于**关闭**状态（开启自动拦截器时无线调试开关呈灰色不可点）。
2. **开启开发者选项**：进入 `设置 → 关于手机 → 软件信息`，连续点击 7 次 **「编译编号」**。
3. 在 `开发者选项` 中打开 **「无线调试」** 并勾选 *始终允许在此网络上调试* 即可。

---

## 6. Google Pixel / 原生与类原生 AOSP

1. 进入 `设置 → 关于手机`，连续点击 7 次 **「版本号」**。
2. 进入 `设置 → 系统 → 开发者选项 → 无线调试`，打开开关并点击「使用配对码配对设备」，下拉通知栏填入 6 位配对码即可完成激活，无需任何额外开关。

---

## 7. 华为 HarmonyOS 兼容性说明

- 华为部分纯血鸿蒙（HarmonyOS NEXT）及深度修改版 HarmonyOS 4.x 在框架层移除了标准 Android `CarrierConfigManager.overrideConfig` 接口。若配对成功后提示系统底层接口受限，属于固件框架层裁剪所致，非配对步骤问题。
