# 常见问题与故障排查手册（FAQ）

---

### Q1：点开「使用配对码配对设备」后，下拉通知栏没有看到输入框怎么办？

请依次检查以下两项：
1. **通知权限是否开启**：返回美境首次激活向导，若看到「请先允许通知权限」提示卡片，点击「去开启」打开通知开关。
2. **校园网 AP 隔离 / 全局 VPN 拦截了局域网组播**：
   - 即使通知栏尚未显示「已识别配对弹窗（端口 xxxx）」，您依然可以直接点击美境常驻通知下方的 **「手填端口与配对码」** 按钮；
   - 对照屏幕上显示的 `IP 地址和端口`（例如 `192.168.1.25:38941`）与 6 位配对码（如 `123456`），直接输入 **`38941 123456`** 提交即可！本机回环 `127.0.0.1` 不经过外部路由器，依然能秒级配对成功。
   - 您也可以使用手机的**分屏 / 小窗模式**打开美境激活向导底部「高级连接选项」手动填入配对端口与 6 位数字。

### Q2：在出门使用 5G 移动流量（没有 Wi-Fi）时，美境还能生效吗？

**完全可以！请记住核心机制：**
- **只要手机没有关机重启**，您在家或办公室连 Wi-Fi 时开启过一次美境，美区运营商配置与 `en-US` 语言就会**一直在系统内存中持续生效**——哪怕您关掉无线调试、断开 Wi-Fi、切到户外 5G 流量，TikTok / Claude / ChatGPT 依然保持美区 T-Mobile 与英文环境！
- 只有在**手机关机重启之后**，才需要连一下 Wi-Fi（或使用手机个人热点 / 另一台设备热点）花 2 秒补写一次电话卡配置。至于各应用的 `en-US` 语言设置则是**永久保留**的，连重启都不会丢失。

---

### Q3：开启美境后，会影响国内手机卡正常接打电话、收验证码短信或使用 5G 流量吗？

**完全不影响。**
- 美境仅在应用读取层覆盖了上报给第三方 App 的国家码（`simCountryIso` → `us`）与显示名称（`T-Mobile`），**不改动任何基带射频参数、APN 接入点、IMSI 或 IMS 注册配置**。
- 您的国内双卡通话、106 短信验证码、5G 上网、微信/支付宝定位与支付均 100% 照常工作。

### Q4：为什么配对成功了，点击「一键开启美境」却提示权限被拦截？

这是国产系统的附加安全开关尚未打开导致的：
- **小米 / REDMI**：请确认已开启开发者选项下方的 **「USB 调试（安全设置）」**；
- **OPPO / 一加 / 真我**：请确认已开启开发者选项最底部的 **「禁止权限监控」**；
- **vivo / iQOO**：请确认同时开启了 **「USB 调试」** 与 **「无线调试」**。

详见 [国产与主流系统真机设置指南](OEM_SETUP_GUIDE.md)。

### Q5：如何彻底恢复国内默认状态或干净卸载？

1. 打开美境主面板，点击最底部 **「一键恢复国内默认状态（还原电话卡与系统中文语言）」** 并确认：
   - 所有电话卡会在 1 秒内恢复为中国移动/联通/电信/广电原归属地；
   - TikTok、X、Claude、ChatGPT 及所有扩展应用会自动恢复为跟随手机系统中文。
2. 即使您直接卸载了美境而忘记点恢复按钮：只需**重启一次手机**，非持久化的电话卡覆盖即会自动清空（单应用语言也可随时在系统「设置 → 应用 → 应用语言」中改回系统默认）。

---

### Q6：我的手机已经获取了 Root 权限（Magisk / KernelSU / APatch），还需要配对无线调试吗？

**不需要！**
打开美境后会自动检测 `su` Root 通道，授予 Root 权限后主界面直接显示 **「通道：Root 直通」**，无需开启开发者选项或连接 Wi-Fi，在任意 5G / 离线环境下均可直接一键秒开与开机秒级恢复。
